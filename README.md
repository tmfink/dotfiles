# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## Local config

Create `lua/config/local.lua` (gitignored) to customize the lazy.nvim config per machine.
See [`lua/config/example.local.lua`](lua/config/example.local.lua) for a commented example.
